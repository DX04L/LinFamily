# 粉紅魔法貓跑酷 (Pink Cat Jump)

以可愛粉白雙色毛絨魔法貓為主角的彩色橫向跑酷網頁遊戲（致敬 Chrome 離線小恐龍 Dino Jump）。

## 特色功能
- **原創角色精細繪製**：完整還原粉白貓耳與寶藍雙絨球、額頭寶藍菱形印記、灰點眉飾、寶藍大眼與玫紅波浪眼眶、寶藍項圈及金黃紅菱形鈴鐺。
- **全彩夢幻場景與日夜切換**：隨分數提升平滑切換「粉彩白晝」與「夢幻紫夜星空」，搭配金色魔法幣收集系統與粒子特效。
- **PC 與手機橫向全螢幕支援**：
  - 內建一鍵全螢幕按鈕（支援 Fullscreen API 與螢幕橫向鎖定）。
  - 手機直立開啟時自動顯示「橫向旋轉引導提示」。
  - 支援鍵盤（空白鍵 / 方向鍵）與手機雙區觸控（左側跳躍、右側長按蹲下）。
- **零外部依賴、離線可玩**：純 HTML5 Canvas + CSS + JavaScript，內建 Web Audio API 合成可愛音效，雙擊 `index.html` 或上傳至任何靜態網站空間（如 GitHub Pages、Vercel、Netlify）即可遊玩。

## 檔案結構
- `index.html`：遊戲主頁面與全螢幕／橫向提示介面
- `style.css`：響應式與手機安全區域（Safe Area）全螢幕樣式
- `game.js`：角色向量繪製、物理跳躍、障礙物生成、日夜轉換與音效系統
